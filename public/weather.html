नेपालको मौसम · Nepal Weather Forecast

यस पृष्ठमा नेपालको मौसम (Nepal weather) को वास्तविक डाटा प्रस्तुत गरिएको छ। काठमाडौं, पोखरा, विराटनगर, ललितपुर, भक्तपुर, भरतपुर, वीरगञ्ज, धरान, बुटवल, नेपालगञ्ज लगायतका प्रमुख शहरहरूको तापक्रम (temperature), आर्द्रता (humidity), हावाको गति (wind speed), सूर्योदय (sunrise) र सूर्यास्त (sunset) समय हेर्न सक्नुहुन्छ।

🌡️ आजको मौसम: शहर र मिति चयन गर्नुहोस्, र Open-Meteo API बाट प्रत्यक्ष डाटा ल्याएर मौसमको पूर्वानुमान देखाइन्छ। ७-दिनको पूर्वानुमान पनि उपलब्ध छ।

नेपालको मौसम किन महत्वपूर्ण छ?

मौसम (weather) को जानकारी नेपाली जीवनको अभिन्न अंग हो। बिदा र छुट्टी, यात्रा, पर्यटन, निर्माण, दैनिक योजनाहरू सबै मौसममा निर्भर हुन्छन्। यस पृष्ठले वास्तविक मौसम API मार्फत सही र अद्यावधिक डाटा प्रदान गर्दछ, जसले गर्दा तपाईंले आफ्नो योजना बनाउन सजिलो हुन्छ।

मौसमका मुख्य तत्वहरू

  • तापक्रम (Temperature): हालको, उच्चतम र न्यूनतम तापक्रम डिग्री सेल्सियसमा
  • आर्द्रता (Humidity): हावामा रहेको नमीको मात्रा प्रतिशतमा
  • हावाको गति (Wind Speed): किलोमिटर प्रति घण्टामा
  • सूर्योदय र सूर्यास्त (Sunrise & Sunset): दिनको प्रकाशको समय
  • मौसम अवस्था (Weather Condition): सफा, बदली, वर्षा, हिउँ, आँधी आदि

कसरी प्रयोग गर्ने?

१. शहर चयन गर्नुहोस् — काठमाडौं, पोखरा, विराटनगर आदि।
२. मिति चयन गर्नुहोस् — आजको, भोलिको वा विगतको कुनै पनि मिति (पछिल्लो ३० दिन देखि अगाडि १६ दिन सम्म)।
३. "हेर्नुहोस्" बटन थिच्नुहोस् वा स्वत: परिवर्तन हुन्छ।
४. मौसम विवरण हेर्नुहोस् — तापक्रम, आर्द्रता, हावा, सूर्योदय/अस्त र ७-दिनको पूर्वानुमान।

API स्रोत

यस पृष्ठले Open-Meteo API को प्रयोग गर्दछ, जसले नि:शुल्क र भरपर्दो मौसम डाटा प्रदान गर्दछ। डाटा प्रत्यक्ष API अनुरोधमार्फत ल्याइन्छ, जसले गर्दा कुनै पनि नमुना वा नक्कली डाटा देखाइँदैन। API उपलब्ध नभएमा प्रयोगकर्तालाई स्पष्ट त्रुटि सन्देश देखाइन्छ।
